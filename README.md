# Expense Tracker

A simple and responsive Expense Tracker web application built using HTML, CSS, and JavaScript.  
This project helps users manage daily expenses by adding, viewing, and deleting expense records while automatically calculating the total amount spent.

---

## 🚀 Features

- Add expenses with amount
- Delete expense entries
- Automatic total expense calculation
- Responsive and clean user interface
- Beginner-friendly project structure

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

---

## 📂 Project Structure

text expense_tracker/ │ ├── index.html ├── style.css └── script.js 

---

## 💡 How It Works

1. Enter the expense name.
2. Enter the expense amount.
3. Click on the Add Expense button.
4. The expense gets added to the list.
5. Total amount updates automatically.
6. Click Delete to remove any expense.
